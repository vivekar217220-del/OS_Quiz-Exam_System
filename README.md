# Quiz and Exam System

A Python/Tkinter classroom prototype for taking multiple-choice quizzes and reviewing results.

| View | Function |
| --- | --- |
| Student | Register or sign in, answer questions, and view the final score. |
| Administrator | Review stored results and manage quiz questions. |

## Run locally

Install Python 3 with Tkinter in a desktop environment, then run this command from the repository folder.

```bash
python Code
```

The app creates `data.json` in the working directory on first launch. It stores questions, scores, and demo accounts in that file. Use demo data for this local prototype.
